How to use this plan (read once before you start)

The plan's shape

  • Monday–Friday: one new lesson each day, followed straight away by an exercise on it.
  • Saturday: practice day. Bigger problems that combine the week's lessons. Also your catch-up day if you missed something.
  • Sunday: review day. You test yourself without notes and redo one exercise from earlier weeks so you don't forget it.
  • Last Sunday of each month: a month test. Pass it before moving on.
  • Dec 28 – Jan 3: a buffer week to catch up if you fall behind.

Every study session, in 4 steps (about 1.5–2 hours)

  1. Read or watch the lesson. Type every code example yourself; don't copy-paste.
  2. Close the lesson tab, then do the exercise from memory.
  3. If you're stuck for 20 minutes, reopen the lesson, find the answer, then close it again and redo the exercise from scratch.
  4. Write 3 lines in a notebook: what you learned, and one mistake you made.

From November

Each day has a main subject (about 60 minutes) and a short C++ part (about 30 minutes), so your programming keeps growing while you learn the math and logic subjects.

Materials you will use

  • C++: learncpp.com lessons, linked directly. If a link ever opens the wrong page, type the lesson title into the search box on learncpp.com.
  • Discrete Structures: Kenneth Rosen, Discrete Mathematics and Its Applications (7th or 8th edition, the standard course book in Pakistan). Section numbers are given for each day. Answers to odd-numbered exercises are at the back of the book.
  • Digital Logic Design: Neso Academy's Digital Electronics playlist on YouTube (the exact video topic is given each day) and nand2tetris.org for building circuits.
  • Security: TryHackMe rooms (free) and the OverTheWire Bandit game.
